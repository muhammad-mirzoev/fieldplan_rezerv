{% trans "Что такое севооборот?" %}

{% trans "Севооборот — это порядок, в котором на одном поле из года в год сменяются культуры. Он помогает сохранить плодородие почвы и снизить болезни и вредителей." %}

{% trans "Зачем чередовать зерновые и бобовые?" %}

{% trans "Бобовые (фасоль, нут, люцерна) накапливают азот в почве, а зерновые его расходуют. После бобовых следующей культуре нужно меньше удобрений, и обычно требуется меньше воды." %}

{% trans "Что делать, если я не знаю тип почвы?" %}

{% trans "Оставьте вариант «Не знаю». Мы возьмём приблизительные данные о почве по координатам вашего поля из открытой базы SoilGrids. Для точного ответа лучше сделать анализ почвы." %}

{% trans "Откуда берутся климатические данные?" %}

{% trans "Из открытых данных NASA: температура и осадки — NASA POWER, снежный покров — MODIS. Это спутниковые оценки, они не заменяют местный прогноз." %}
